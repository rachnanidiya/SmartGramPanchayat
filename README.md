 Smart Gram Panchayat

Smart Gram Panchayat is a web application developed to digitalize village administration services. It provides citizens with online access to government schemes, complaint registration, village updates, and profile management.

1. Features

- Complaint registration portal
- Government scheme information
- Online scheme application
- Village news and updates
- User profile dashboard
- Admin approval system

2. Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Django
- Database: SQLite

3. Installation

1. Clone the repository:
   git clone <repository-link>

2. Navigate to project directory:
   cd smart-gram-panchayat

3. Install dependencies:
   pip install django

4. Apply migrations:
   python manage.py migrate

5. Run server:
   python manage.py runserver

4. Objective

The project aims to simplify rural governance by providing an online platform for accessing village-related services and improving transparency.
